# FitLog — Workout Library

##  Short Description

FitLog is a modern and responsive workout library application built with Next.js. Users can explore workouts, view exercise details, create a daily workout plan, and save workouts for later.

##  Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Context API
* REST API
* LocalStorage

##  Key Features

1.  **Workout Library** — Browse and explore different workouts with images, categories, equipment, duration, calories, and ratings.

2. **Today's Plan** — Add up to five workouts to your daily workout plan and track your exercises.

3. Save for Later** — Save your favorite workouts and access them anytime from the Saved section.

4. Workout Tracking** — Track total exercises, workout minutes, and calories in your daily plan.

5. Fully Responsive** — The application works smoothly on mobile, tablet, and desktop devices.
